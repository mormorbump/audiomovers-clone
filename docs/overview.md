# MusicMovers アーキテクチャ概要

macOSのシステム音声を非圧縮24bit PCMでリアルタイムにブラウザへ配信するアプリケーション。

## コンポーネント詳細

### 1. 音声キャプチャ層

| コンポーネント | 役割 |
|---------------|------|
| **BlackHole 2ch** | macOSカーネルレベルの仮想オーディオドライバ。アプリの音声出力をキャプチャ可能にする |
| **複数出力装置** | BlackHoleとスピーカーに同時出力するmacOSの機能 |
| **sox** | BlackHoleから24bit PCMでキャプチャし、stdoutに出力 |

### 2. サーバー層 (`src/server/index.ts`)

| コンポーネント | 役割 |
|---------------|------|
| **HTTPサーバー** | 静的ファイル（HTML/JS）を配信 |
| **WebSocketサーバー** | 接続中の全クライアントにPCMデータをブロードキャスト |
| **sox子プロセス** | 音声キャプチャを管理、異常終了時は自動再起動 |

### 3. クライアント層

| ファイル | 役割 |
|---------|------|
| **player.js** | WebSocket接続、AudioContext管理、UI更新 |
| **worklet-processor.js** | 24bit PCMデコード、Ring Bufferでバッファリング、オーディオ出力 |

## データフロー

### PCMフォーマット

```
┌─────────────────────────────────────────────────────────────┐
│  24bit Stereo Interleaved Little-Endian PCM                │
├─────────────────────────────────────────────────────────────┤
│  Sample Rate: 48,000 Hz                                    │
│  Bit Depth:   24bit (3 bytes/sample)                       │
│  Channels:    2 (Stereo)                                   │
│  Byte Order:  Little-Endian                                │
│  Interleave:  L0 L1 L2 R0 R1 R2 L0 L1 L2 R0 R1 R2 ...     │
├─────────────────────────────────────────────────────────────┤
│  帯域幅: 48000 × 24 × 2 = 2,304,000 bps ≒ 2.3 Mbps        │
│  チャンクサイズ: 2048 samples × 2ch × 3bytes = 12,288 bytes │
└─────────────────────────────────────────────────────────────┘
```

### チャンク送信フロー

```
sox stdout → Buffer蓄積 → 12,288バイトごとに分割 → WebSocket送信 → 全クライアント
```

## 技術的な特徴

### なぜ非圧縮PCM？

| 方式 | レイテンシ | 音質 | 帯域 |
|------|-----------|------|------|
| **非圧縮PCM** | 最小（エンコード/デコード不要） | ロスレス | 高（2.3Mbps） |
| Opus | 中（エンコード/デコード必要） | 高品質 | 低（64-256kbps） |
| MP3 | 高 | 低品質 | 低（128-320kbps） |

このアプリはローカルネットワーク/Cloudflare Tunnel経由での使用を想定しており、帯域より低レイテンシを優先。

### Ring Buffer

AudioWorkletは128サンプル（約2.67ms）ごとに`process()`が呼ばれる。ネットワーク遅延によるデータ到着のばらつきを吸収するため、2秒分のRing Bufferを使用。

### プリバッファリング

再生開始時、300ms分のデータが蓄積されるまで再生を開始しない。これによりバッファアンダーラン（音切れ）を防止。
